# Technical Blog Writer

A Codex skill for writing in-depth Chinese technical articles.

从一个技术概念出发，主动检索资料、与你确认大纲，再生成中文 Markdown 文章。讲清原理、设计取舍与技术演进，结构自然，代码优先使用伪代码，参考资料统一列在文末。

## 安装

在 Codex 中输入：

```text
使用 $skill-installer 安装：
仓库：https://github.com/cardchoosen/technical-blog-writer
路径：skills/technical-blog-writer
```

## 使用

```text
使用 $technical-blog-writer 写一篇关于「一致性哈希」的文章。
```

先讨论大纲，确认后完成正文。可以补充读者基础、讲解重点和保存位置。资料检索需要运行环境提供搜索或网页读取能力。

- **改稿**：说明文章路径和修改建议，调整指定部分及直接相关内容。
- **核验**：主动要求「核验与通读」时，检查文章并报告问题；要求「核验并修正」时直接改稿。
